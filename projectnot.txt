৩. মার্কেটিং প্ল্যান (কোডে স্থির — backendserver/src/Engine/Plan.php)
---------------------------------------------------------------------
প্যাকেজ / Activation: ৳১,০০০ = 1000 BV। ভাগ:
- Cashback ৳১০০ — শুধু সার্ভিসে খরচ, তোলা যায় না
- Direct Referral ৳২০০ — সরাসরি sponsor, activation-এর সাথে সাথে
- Matching Reserve ৳৩০০ — এক sale থেকে সর্বোচ্চ ১১টি matching:
  150, 75, 37.5, 18.75, 9.375 ... (প্রতিবার অর্ধেক), মোট সর্বোচ্চ ৳২৯৯.৮৫৪
- Generation Pool ৳২০০ — ১০ লেভেল GEN-01..GEN-10:
  50 / 30 / 25 / 20 / 18 / 15 / 12 / 10 / 10 / 10
- Rank Pool ৳২০০

Matching
- Daily Matching Cap: প্রতি active ID দিনে ৳৫,০০০
- Binary (placement) tree আর Enrollment (sponsor) tree আলাদা।
  দুটোর হিসাব আলাদা হয়, কিন্তু Central Matching Selection Engine একটাই
  Final Matching দেয় — এক sale = সর্বোচ্চ একটি final matching credit।
  Double matching/double commission নয়।
- Total Matching = Rank Matching = cap ও selection-এর পরে অনুমোদিত matching।
- Major Link: অব্যবহৃত carry সবসময় পরের দিনে যায়।
- Minor Link: daily cap অনুযায়ী, রাত ১২টার পর counter শূন্য দেখায়।
- একবার ব্যবহৃত volume আর কখনও ব্যবহার হয় না; প্রতিটি volume-এর উৎস sale
  lo_volumes / lo_volume_pairs-এ লেখা থাকে (audit-এর জন্য)।

Rank (lo_ranks — matching সংখ্যা অনুযায়ী)
  Member 0 · Silver Executive 100 · Gold Executive 300 · Gold/Executive 1,000 ·
  Platinum Executive 5,000 · Diamond Executive 25,000 · Crown Executive 125,000 ·
  Ambassador 500,000 · Global Ambassador 1,500,000
  (নতুন rank নাম রাখার সিদ্ধান্ত। rank reward-এর টাকা admin হাতে দেন —
   নির্দিষ্ট অঙ্ক এখনও ঠিক হয়নি।)

Wallet
- D Wallet = Deposit wallet (Active New ID-তে খরচ হয়)
- E Wallet = Earning/Withdraw wallet (তোলা যায়)
- Cashback wallet = পুরোনো ব্যালেন্স + ৳১০০ cashback (service-only)
- E → D swap চার্জ ৪% (transaction password লাগে)
- Withdrawal চার্জ ১০%
- নতুন টাকার ফিচার (transfer, recharge) admin চালু না করা পর্যন্ত বন্ধ।
- Admin feature switch ও withdrawal limit PHP সার্ভারে যাচাই হয় (PanelPolicy)।

৪. কাজের ধারা (workflow)
---------------------------------------------------------------------
Registration (/join)
1. Sponsor referral link বা sponsor code / Account ID / username দিয়ে।
2. Left / Right দল বেছে নেওয়া; placement সার্ভার নিজে খুঁজে বসায়
   (ফর্মে placement দেখায় না, browser-এর দেওয়া placement বিশ্বাস করা হয় না)।
3. নতুন Account ID = ৬ সংখ্যার নম্বর (যেমন 806246)। এই ID-ই username,
   life_id, membership_no। পুরোনো LID-2026-... ও পুরোনো hex ID অপরিবর্তিত।
4. Register শেষে popup-এ Account ID + password; ছবি হিসেবে save করা যায়।
5. Blood group, NID, District, Post code, Address পরে Profile Edit-এ।
6. Binary tree-র খালি জায়গার "+" চাপলে সেই জায়গায় Register ফর্ম খোলে।

Login (/login): Account ID/username + password + captcha (৪ সংখ্যা, সার্ভারে
তৈরি ও একবার ব্যবহার)। Cancel বোতাম নেই, Register লিংক আছে।

Activation
- Payment SUCCESS হলেই activation; Pending/Failed/Reversed হলে নয়।
- একই Transaction ID দিয়ে দুবার activation/কমিশন নয়।
- Active New ID: D Wallet থেকে ৳১,০০০ কেটে সাথে সাথে active (pending নয়)।
- Direct Referral তখনই; Matching + Generation + বাকি সব রাত ১২টায়।
- কমিশন না হলে System Error Log-এ লেখা হয়।

Daily Closing (প্রতিদিন বাংলাদেশ সময় রাত ১২টা)
 data freeze → eligible activation যাচাই → enrollment+binary matching →
 daily cap → final matching selection → generation → Major carry update →
 Minor counter reset → commission ledger → member dashboard update।
 আজকের তারিখ সবসময় MySQL CURRENT_DATE() থেকে।

Cron (cPanel → Cron Jobs → Once Per Minute)
  /usr/local/bin/php '/home/lifeosbd/public_html/backendserver/bin/cron-http.php'
  (পথ আপনার cPanel অনুযায়ী মিলিয়ে নিন। Admin → Configs → Cron Setup পাতায়
   ঠিক কমান্ড copy করা যায়।) URL: <domain>/backendserver/api/public/cron/settle
  — শুধু HMAC-signed POST গ্রহণ করে, URL-এ key থাকে না।
  টাকা দিতে দুটো অনুমতি লাগে: runtime.php-তে cron_http_execute=true এবং
  admin setting financial_release_approved=1। midnight payout এখন চালু।

Placement সংশোধন: শুধু Admin → Placement Correction, audit log সহ।
